STUDY TRACKER WEBSITE — UPLOAD GUIDE

CONTENTS
- index.html: the complete responsive website
- assets/: generated promotional images used by the website
- downloads/StudyTracker.exe: the Windows desktop application from your uploaded ZIP

HOW TO PUBLISH
1. Extract this website ZIP on your computer.
2. Open your hosting control panel's File Manager (or use FTP).
3. Open the website root folder. It is commonly named public_html, www, or htdocs.
4. Upload index.html and the assets and downloads folders together.
5. Keep the folder names and structure unchanged.
6. Visit your domain and test the Download buttons.

IMPORTANT
- The download buttons point to downloads/StudyTracker.exe. Keep the EXE at that exact relative path, or update the href values in index.html if you host it elsewhere.
- The EXE is included in this package (about 21 MB). Check your free hosting provider's file-size, storage and bandwidth limits before uploading.
- The feature illustrations are AI-generated promotional artwork, not literal screenshots of the running app.
- The website uses Google Fonts when internet access is available and falls back to system fonts otherwise.
